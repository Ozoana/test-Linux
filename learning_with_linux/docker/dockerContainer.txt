#docker container

jika sebelum nya image itu seperti instal aplikasi, maka docker container ini adalah hasil dari aplikasi tersebut, tapi dia bisa gunakan 1 image untuk banyak container, asal nama nya beda
maksud nya atau contoh nya, misal kita docker pull php:latest (kita dowload php versi terbaru nya) maka kita bisa gunakan image itu untuk membuat container, misal kita buat container "coba1" dari image Php ini, terus kita buat lagi, container "coba2" dari image yang sama, ya itu image Php
jadi 2 container tersebut bisa gunakan bahasa php dan jika kita sudah gunakan suatu image maka image yang digunakan tersebut tidak bisa di haous, ini terjadi karena container yang di buat menggunakan image tersebut, bukan di copy isi image nya.

#cara buat container
perintah = docker container create --name coba1 php:latest

#cara jalankan container
perintah = docker container start containerID/nameContainer 
(untuk bagian containerID/nameContainer itu maksud nya bisa di isi container id nya atau nama container nya, jadi 2 cara, bebas aja)

#cara menghentikan container yang sedang jalan 
perintah = docker container stop containerID/nameContainer 
(untuk bagian containerID/nameContainer itu maksud nya bisa di isi container id nya atau nama container nya, jadi 2 cara, bebas aja)

#cara hapus container 
docker container rm containerID/nameContainer 
(untuk bagian containerID/nameContainer itu maksud nya bisa di isi container id nya atau nama container nya, jadi 2 cara, bebas aja)
dan perlu di ingat, container ini tidak bisa di hapus sebelum dia di hentikan, jadi hentikan dulu, baru bisa di hapus

#cara liat container
cara lait semua docker container yang kita buat, mau itu dijalankan atau tidak
perintah : docker container ls -a

cara lait container yang sedang berjalan saja : docker container ls 
nanti disini ada port, jika port itu tidak apa apa misal nya container lain berjalan di port yang sama, karnea container ini sistem nya terisolasi, jadi tidak akan bentrok, dia gunakan port dai container tersebut, bukan dari sistem komputer nya gitu.
